## Development Setup & Lessons (1,000+ hours)
| # | Lesson | Key Detail |
|---|--------|------------|
| 1 | **Vibe coding ≠ fast** | AI enabled a solo build previously unrealistic, but still took **1,000+ hours** |
| 2 | **Automated tests are essential** | **8,400+ tests** prevent regressions; Claude can refactor safely |
| 3 | **Parallel Claude sessions** | Git worktrees + branches → multiple Claude instances working simultaneously |
| 4 | **Give AI repeatable workflows** | Custom Claude Code skills for: releases, art generation, wiki updates, save recovery |
| 5 | **Don't blindly trust AI code reviews** | Tested another AI reviewer: **20 "critical bugs" reported → 0 valid** |
| 6 | **Building = half the battle** | Player acquisition is equally hard |

## Player Acquisition — What Didn't Work
- YouTube Shorts
- Repeated promotional posts
- Most developer subreddits

## Core Takeaways
1. **Audience ≠ Users** — Developers may admire your project but won't play it. Target people who *actually want to use* what you're building.
2. **UTM Everything** — Without tracking links, you're guessing where users come from.
3. **AI Amplifies, Doesn't Replace** — 1,000+ hours still required; tests, workflows, and parallelization make it sustainable.
4. **Live Ops Matter** — Game is in open beta, improving based on player feedback.
